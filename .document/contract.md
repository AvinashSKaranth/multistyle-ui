# multistyle-ui — Token & file contract (Phase 1)

Authoritative alongside `plan.md`. Build: `npm run build` (-> `dist/` 2 files, copied to `docs/`). Dev: `npm run dev`.

## 1. Layers
`@layer ms.reset, ms.tokens, ms.base, ms.style, ms.utils;` (declared in `src/css/index.css`).
Every CSS file wraps its rules in its own `@layer x { ... }` block (esbuild preserves it).
- `ms.base`: component rules (classless + opt-in classes). Material look is the DEFAULT here (no `.style-material` needed).
- `ms.style`: per-style overrides.

## 2. Scope selector
Tokens derive on `:root, [class*="theme-"], [class*="mode-"], [class*="style-"]` so any element with a ms class re-derives (scoped sections). **Do not use class names containing `theme-`, `mode-` or `style-` for other things** (they'd be treated as scopes; input tokens reset on `theme-*`).

## 3. Input tokens (set by themes/users; components must NOT read these)
`--ms-primary --ms-secondary` colors · `--ms-surface --ms-text` (may be `light-dark()`) · `--ms-card` (unset => derived from surface-2) · `--ms-info --ms-success --ms-warning --ms-error` · `--ms-radius-btn --ms-radius-card --ms-radius-input --ms-border-w` · `--ms-font` (font stack; styles set it on `.style-x`).
Fixed defaults on `:root`: `--ms-default-surface-light/-dark` (#fff/#13171f), `--ms-default-text-light/-dark` (#0f172a/#e6e9ef), `--ms-space` (1rem), `--ms-font-size`, `--ms-line-height`, `--ms-transition` (.15s ease).
Defaults (no theme class) = blue (#2060df / secondary #0172ad). `theme-custom`: user sets `--ms-primary/--ms-secondary/--ms-surface` inline; surface is light-mode only.

## 4. Effective tokens (components read ONLY these)
Colors (all mode-aware; primary/secondary are lifted to L>=0.68 in dark):
`--ms-c-primary --ms-c-secondary` · `--ms-c-on-primary --ms-c-on-secondary` (auto black/white) · `--ms-c-surface` page bg · `--ms-c-surface-2` cards/raised (4% text) · `--ms-c-surface-3` hover/inputs (8%) · `--ms-c-card` card bg (theme card or surface-2) · `--ms-c-text` · `--ms-c-muted` · `--ms-c-disabled` · `--ms-c-border` · `--ms-c-focus` (45% primary, translucent; for rings) · `--ms-c-shadow-color` (18% primary translucent).
Status: `--ms-c-info|success|warning|error`, `-subtle` (14% on surface, backgrounds), `-strong` (darkened, text on subtle).
Shades: `--ms-c-primary-{50,100,200,300,400,500,600,700,800,900,950}` and `--ms-c-secondary-*` (500 = base; 50-400 mixed with white, 600-950 with black).
Shape: `--ms-c-radius-btn --ms-c-radius-card --ms-c-radius-input --ms-c-border-w`.
Misc (not `-c-`, declared on scopes): `--ms-shadow-sm|md|lg`, plus `:root` `--ms-transition --ms-space --ms-font-size --ms-line-height`.
Text on a status/subtle background: use `--ms-c-*-strong`; on filled status color use `#fff`.
Body paints `background: var(--ms-c-surface); color: var(--ms-c-text); font-family: var(--ms-font)`. Scoped scopes also get bg/color (zero specificity).

## 5. Mode
`:root{color-scheme: light dark}`, `.mode-light`, `.mode-dark`. JS removes the class for `system`. Never write `@media (prefers-color-scheme)`; rely on tokens/`light-dark()`.

## 6. Lists
- Styles (12): material(default), material3, fluent, brutalist, pixel, neon, metro, bootstrap, cartoon, illustration, carbon, liquid-glass.
- Themes (30): Pico 19 (red pink fuchsia purple violet indigo blue azure cyan jade green lime yellow amber pumpkin orange sand grey zinc) + repo-named: classic ocean forest rose midnight gold slate candy storm royal + custom. **slate uses repo values** (#64748b/#475569, tinted card, 6/8/6px radii, 1px border), not Pico's slate-550.
- Pico themes set only primary/secondary (550 hex; secondary = next hue's 550, neutrals use own 650). Named themes also set surface/card/text (`light-dark`, dark via build-time HSL invert, lifts text 20/surface 10/card 14), status colors, radii, border width. Dark-native: midnight, storm, royal.
- `themes.css` is generated by `scripts/gen-themes.js` — never edit.

## 7. File ownership
| Path | Owner |
|---|---|
| `scripts/*`, `src/css/{index,reset,tokens,utils}.css`, `src/js/index.js`, package.json | Phase 1 (this) |
| `src/css/components/*.css` + add `@import "./x.css";` to `components/index.css` | components agent |
| `src/css/styles/<style>.css` + add `@import` to `styles/index.css` | styles agent |

## 8. Writing a component file (ms.base)
```css
@layer ms.base {
  :where(button, [role="button"], input:is([type=submit],[type=button],[type=reset])) {
    background: var(--ms-c-primary); color: var(--ms-c-on-primary);
    border: var(--ms-c-border-w) solid var(--ms-c-primary);
    border-radius: var(--ms-c-radius-btn); transition: all var(--ms-transition);
  }
  :where(button:hover) { background: var(--ms-c-primary-600); }
  :where(button:focus-visible) { outline: 3px solid var(--ms-c-focus); outline-offset: 2px; }
}
```
Rules: wrap selectors in `:where()` (zero specificity); only `--ms-c-*`/`--ms-shadow-*`/`--ms-space`/`--ms-transition` tokens (never `--ms-primary` etc. directly); no hard-coded colors except `#fff`/`transparent`; no media-query dark mode; one file per component.

## 9. Writing a style file (ms.style)
```css
@layer ms.style {
  :where(.style-brutalist) {          /* the style element itself: shape tokens + font */
    --ms-c-radius-btn: 0; --ms-c-radius-card: 0; --ms-c-radius-input: 0; --ms-c-border-w: 2px;
    --ms-font: 'Courier New', ui-monospace, monospace;
  }
  :where(.style-brutalist) :where(button) { box-shadow: 4px 4px 0 var(--ms-c-text); }   /* descendant selectors */
}
```
Prefer overriding shape tokens/`--ms-font`/`--ms-shadow-*` on `.style-x` itself; add element rules only where tokens can't express the look. Always descendant form `:where(.style-x) :where(el)` (never `body.style-x`) so scoped sections work. Known caveat: a nested `.theme-*` scope re-derives shape tokens from theme values, so style shape overrides do not pass through a nested theme scope (put `style-x` and `theme-y` on the same element, or restate).
Fonts: set `--ms-font` with system fallbacks; never `@import` fonts (JS lazily loads Google Fonts for: material/material3 Roboto, neon Exo 2, cartoon Comic Neue, illustration Dancing Script, carbon IBM Plex Sans).

## 10. JS API (`window.MS`)
`MS.styles|themes|modes` arrays · `MS.get(el=body)` -> `{style,theme,mode,resolvedMode}` · `MS.set({style,theme,mode,primary,secondary,surface}, el=body)` (passing a color without theme => `custom`; non-body `el` fires no event/persist) · `MS.toggleMode()` · `MS.font(style)` · `MS.resolveColor('--ms-c-primary' | any css color, el)` -> `rgb()/rgba()` string safe for Chart.js · `MS.lightness(color)` (OKLab L) · `MS.open(sel|el)` / `MS.close(sel|el)` for `<dialog>`.
Events: `document` `ms:change` (detail = `MS.get()`), also fired when OS scheme changes in system mode.
Declarative: `<select data-ms="style|theme|mode">` (auto-populated if empty), `[data-ms-mode-toggle]`, `[data-ms-open="#id"]`, `[data-ms-close]` (optional selector; else closest dialog), `<body data-ms-persist>`, `<body data-ms-fonts="off">`.
Alpine: `$store.ms`, `$ms` magic (needs multistyle script loaded before Alpine).
Extension modules: each of `toast.js tabs.js ripple.js chart.js` exports `init(MS)`, called after DOM ready; they attach to `MS` (e.g. `MS.toast`, `MS.chart`).
