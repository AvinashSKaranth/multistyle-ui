# Icons

Material Symbols Outlined via `<span class="ms-icon" aria-hidden="true">star</span>` (ligature name). `.filled` = solid. The font loads from Google Fonts when a `.ms-icon` exists; `body[data-ms-icons=off]` to self-host. Needs network; keep a text label or `aria-label`.
```html
<button><span class="ms-icon" aria-hidden="true">star</span> Favourite</button>
```
