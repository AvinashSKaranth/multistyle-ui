# Typography, nav, tooltip, accordion, fieldset

All classless: headings, blockquote, kbd, mark, small. `nav` and `nav[aria-label=breadcrumb]`. Tooltip: `data-tooltip="text" data-placement="top"`. Accordion: `details[name=group]` is exclusive. Fieldset groups fields; flag with `aria-invalid="true"` and a following `small`.
