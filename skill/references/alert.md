# Alert

`<div role="alert" data-type="success|warning|error|info"><strong>Title</strong>Message<button class="close" aria-label="Close" data-ms-dismiss></button></div>`. Default icon per type; `data-icon="none"` removes it. `[data-ms-dismiss]` removes the closest alert, `.chip`, `.ms-toast` or `[data-ms-dismissable]` and fires `ms:dismiss`.
